# GFG. Sum of Natural Number Cubes
**Platform:** GeeksforGeeks
**Difficulty:** N/A
**Topic:** Mathematical

## Problem Statement
Given an integer n, calculate the sum of series 13 + 23 + 33 + 43 + … till n-th term.

Examples:

Input: n = 5
Output: 225
Explanation: 13 + 23 + 33 + 43 + 53 = 225
Input: n = 7
Output: 784
Explanation: 13 + 23 + 33 + 43 + 53 + 63 + 73 = 784

Constraints:
1 <= n <= 200

# GFG. Inverted Triangle of Stars
**Platform:** GeeksforGeeks
**Difficulty:** N/A
**Topic:** pattern-printing

## Problem Statement
Given an integer n, print an inverted isosceles triangle of stars such that the height of the triangle is n.

Examples:

Input: n = 4
Output: 
*******
 *****
  ***
   *
Input: n = 3
Output:
*****
 ***
  *

Constraints:
1 ≤ n ≤ 100
